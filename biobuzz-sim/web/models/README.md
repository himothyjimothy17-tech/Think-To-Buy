# Optional real CAD models

Put these files here and reload the page (no restart needed):

| File         | What it replaces                         |
|--------------|------------------------------------------|
| `field.glb`  | the generated field (tiles, walls, FLOWERS, HIVE frame) |
| `robot.glb`  | our generated robot                      |
| `models.json`| optional: scale / rotation / offset / part names |

If a file is missing the generated model is drawn. See the README section
"Using real CAD" for how to export and line the models up.
